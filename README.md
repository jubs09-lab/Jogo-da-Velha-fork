
# Jogo da Velha

Projeto desenvolvido com HTML, CSS e JavaScript.

## Sobre o projeto

Este jogo permite que dois jogadores participem de uma partida de jogo da velha, utilizando os símbolos X e O.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Projeto de referência

## O que aprendi com o projeto

Ao estudar o projeto de referência, aprendi novas formas de organizar os arquivos CSS e JavaScript e melhorar a aparência da interface.

Aproveitei essas ideias para aprimorar a apresentação visual do meu próprio jogo, mantendo sua estrutura e funcionalidades.
